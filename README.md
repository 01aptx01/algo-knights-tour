# Knight's Tour Lab

Interactive visualizer that compares Warnsdorff's heuristic with classic
backtracking for open and closed knight's tours.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static
web server. No build step or runtime dependencies are required.

## Format code

```sh
npx --yes prettier --write app.js index.html style.css
```
